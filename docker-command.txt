1. merakit docker image dan kasih label nama
docker build -t back-air-capstone:v1

2. periksa daftar docker image yang berhasil dibuat docker images

3. menjalankan container secara detached (-d) dengan port 5000:5000
docker run -d -p 5000:5000 --name container_ai_app backend-ai-capstone:v1

4. memeriksa status kontainer yang sedang berjalan
docker ps
